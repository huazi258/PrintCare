## 本轮发现并修复的必要缺陷

1. 并行检索节点在无结果或跳过时回传整个 LangGraph state，导致 `session_id` 等标量并发写入并触发 `InvalidConcurrentGraphUpdate`。现仅回传本节点拥有的增量字段。
2. Web 检索节点有调试 `print`，在 Windows GBK 控制台遇到网页 Unicode 内容时可能使真实 QA 任务失败。已移除。
3. 已部署 Milvus 的混合检索未替换参数化表达式中的 `{device_id}` / `{item_names}`，造成实际 K1 数据存在但检索为零。改为服务端已验证值生成的 JSON 字面量表达式，恢复设备范围内检索。
4. 诊断模型在重复追问的有限重试耗尽后会走系统失败。现安全降级为 `insufficient`，不重复询问已答事实，也不产生无依据建议。
5. 诊断详情无法区分仍有执行租约的处理中会话与已失败、尚无决策的会话；SSE 静默重连也可能令页面无限等待。服务端现在提供持久化 `processing` / `active_task_id`，前端增加有限的 SSE 无事件超时和安全恢复界面。
