## 6. 缺陷与修复

### 已修复：Reranker 的 Windows 控制台编码中断

真实首层检索首次暴露 Reranker 会把完整文档直接 `print()` 到 GBK 控制台。K1 手册含无法编码字符时，`print()` 抛出编码异常，Rerank 捕获后退化为所有文档无分数。

本轮移除了这些调试 `print()`，保持排序算法不变，并新增覆盖无法由 ASCII stdout 编码的手册字符的测试。修复后，真实 Reranker 可完成评分和断崖截断。

### 仍未解决：真实 LLM 候选持续触发 `invalid_support`

修复 Reranker 后重新执行首层真实 HTTP 诊断，结果仍为 `validation_rejected / invalid_support`。这说明当前 Prompt 与严格逐字 `support_text` 校验在真实模型输出上不稳定；不能为通过验收而放宽证据或高风险规则。需在后续任务中以可审计的候选样本定位 Prompt 约束、资料文字质量与支持片段匹配策略，再重新进行真实验证。
