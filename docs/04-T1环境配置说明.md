# T1 环境配置说明

PrintCare K1 的 T1 导入与查询服务必须指向同一组专用 Milvus Collection：

```ini
CHUNKS_COLLECTION=printcare_k1_chunks_v1
ITEM_NAME_COLLECTION=printcare_k1_item_names_v1
```

这两个 Collection 必须在导入或查询前正确创建。初始化与 Schema/索引处理沿用
`knowledge/processor/import_process/nodes/import_milvus.py` 的现有逻辑。

不要把旧的 `kb_chunks_v1` 或 `kb_item_names_v1` 直接作为 K1 T1 数据源：历史数据
不具备本阶段所需的设备归属字段。新旧 Collection 应保持隔离。

实际运行配置保存在本地 `knowledge/.env`，该文件可能包含密钥，不能提交。请根据本机
Milvus 与模型配置创建自己的 `.env`；不要复制或提交真实凭据。
